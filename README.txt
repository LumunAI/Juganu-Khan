JUGANU KHAN INSULATION WORKS — STANDALONE WEBSITE

HOW TO OPEN DIRECTLY
1. Extract the ZIP file to a folder.
2. Double-click index.html.
3. It opens in your default browser. No npm install, server, or internet connection is required for the core page layout and interactions.

WHAT WORKS OFFLINE
- Responsive single-page website with mobile navigation.
- Services, industries, project sample section, FAQs, and contact form.
- Clicking a service enquiry preselects that service in the contact form.
- Submitting the form downloads the enquiry details as a .txt file. No data is sent automatically.

BEFORE PUBLISHING
- Replace sample gallery copy with real project photos.
- Add the real phone number, email address, business location, and WhatsApp number.
- To receive enquiries automatically online, deploy a hosted version and connect a real form/email service or configure a WhatsApp link.

VERCEL NOTE
This is a standalone index.html page. It can also be hosted as a static site. For Vercel, upload index.html to a GitHub repository and import the repository into Vercel; no Next.js build is needed for this version. Add a custom domain later through Vercel's project domain settings.
